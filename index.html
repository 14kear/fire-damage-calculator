Как выполняется расчёт

Вводятся уже нормированные значения Xᵢ = Yᵢ / Mᵢ, где Mᵢ — максимум своего столбца. Система решается методом Рунге–Кутта. Для вывода в исходных единицах применяется Yᵢ = Xᵢ · Mᵢ; денежные значения из Excel дополнительно умножаются на 1000 для перевода в рубли.

t — шкала времени статьи: значения 0; 0,1; …; 0,7 сопоставлены годам 2015–2022. τ = t/T — доля интервала. Денежные величины в исходной таблице указаны в тысячах рублей.

J = ∫₀ᵀ Σ γᵢ(Xᵢ − Xᵢ*)²dt — критерий отклонения от выбранной цели. Он не является суммой ущерба.

Исходная статистика

«Статистика Путилов.xlsx», восемь наблюдений за 2015–2022 годы. X₁ и X₂ — люди; X₃…X₁₅ — тысячи рублей. Общий ущерб X₃ не складывается повторно с ущербом по причинам.
