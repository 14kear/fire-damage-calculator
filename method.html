1. Постановка задачи и характеристики системы X1(t)–X15(t)

Для оценки, прогнозирования и минимизации социально-экономических последствий пожаров на промышленном предприятии используется аппарат системной динамики. На временном интервале t ∈ [0; T] (T ≤ 1) состояние системы описывается пятнадцатью безразмерными нормированными характеристиками X1(t)…X15(t), приведёнными к единой шкале [0; 1] по статистическим сборникам ФГБУ ВНИИПО МЧС России «Пожары и пожарная безопасность»:

Xi(t) = Yi(t) / Ximax,    i = 1, …, 15,    0 ≤ Xi(t) ≤ 1.

Целевая функция управления состоит в минимизации отклонений актуальных характеристик Xi(t) от допустимых (предельных) значений Xi*, определяющих границу красной зоны на радиальных (лепестковых) диаграммах:

J(T) = ∫0T Σi=1..15 γi · (Xi(t) − Xi*)2 dt → min,    γi = 1 / 15.

2. Внешние возмущения E1(t)–E5(t)

Внешние условия функционирования промышленного объекта и меры противопожарной профилактики задаются пятью функциями возмущений E1(t)…E5(t) со значениями на отрезке [0; 1]:

Em(t) = cm + bm·t + am·t2,    m = 1, …, 5,    0 ≤ Em(t) ≤ 1.

4. Численный метод Рунге–Кутта 4-го порядка

Задача Коши при заданных начальных условиях Xi(0) ∈ [0; 1] решается численно методом Рунге–Кутта 4-го порядка с шагом h = T / N (N = 200) при соблюдении ограничений нормированной шкалы 0 ≤ Xi(t) ≤ 1:

k1 = F(tn, Xn),   k2 = F(tn + h/2, Xn + h·k1/2),   k3 = F(tn + h/2, Xn + h·k2/2),   k4 = F(tn + h, Xn + h·k3),
Xn+1 = Xn + (h / 6)·(k1 + 2k2 + 2k3 + k4).
